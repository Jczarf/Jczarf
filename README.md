## About

I enjoy engineering work that crosses boundaries instead of fitting into a single title. My projects span **web applications, Linux tooling, infrastructure, automation, security, and AI-assisted development**.

I like taking a problem from idea to a working system: understanding the requirements, shaping the architecture, implementing the software, testing it, deploying it, and improving it from real failures and constraints.

- **Computer Science undergraduate** and **Systems Development Technician**.
- Building full-stack applications with modern JavaScript/TypeScript ecosystems.
- Working close to **Linux, containers, CI/CD, databases, and production environments**.
- Applying **security, testing, observability, and maintainability** as part of development — not as an afterthought.
- Using **LLMs and coding agents** for research, planning, implementation, review, testing, and documentation, with human validation before changes are accepted.

## Selected work

### Residential Management Platform · private project

End-to-end web system for **property, tenant, contract, billing, document, and administrative workflows**.

`Next.js` · `React` · `TypeScript` · `Node.js` · `Express` · `Prisma` · `PostgreSQL` · `Docker`

The project goes beyond CRUD: it includes authentication and access control, WebAuthn MFA, responsive administrative interfaces, automated checks, containerized delivery, database migration procedures, backup/restore validation, and production security hardening.

### J.A.R.V.I.S. — Linux Assistant · private project

Desktop Linux assistant combining **LLMs, function calling, local tools, system telemetry, and automation** behind an explicit execution boundary.

`Python` · `PySide6 / Qt 6` · `SQLite` · `Linux` · `GitHub Actions`

The project explores modular architecture, desktop UI, optional local memory, safe-by-default tool execution, portability across Linux environments, testing, CI, and practical human-in-the-loop use of AI.

### Academic foundations

My public [Faculdade](https://github.com/Jczarf/Faculdade) repository contains academic work and programming exercises, including projects in **C** focused on programming fundamentals, control flow, functions, recursion, and problem solving.

## How I approach engineering

```text
Understand the problem
        ↓
Design the simplest sound solution
        ↓
Implement + test + review
        ↓
Automate what should be repeatable
        ↓
Deploy with explicit safety checks
        ↓
Observe, learn, improve
```

I value **clear architecture, secure defaults, reproducible environments, useful tests, readable code, and documentation that reflects the real state of a project**.
